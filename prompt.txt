**Especificaciones del Sistema:**
El sistema debe evitar sonar robótico. Para lograrlo, es necesario implementar un enfoque híbrido:

1. **Detección y Configuración Multilenguaje:** El módulo debe ser capaz de identificar el idioma de entrada dinámicamente y cargar los recursos lingüísticos correspondientes.
2. **Sustitución Inteligente (Diccionarios):** Se debe implementar tokenización, lematización y etiquetado gramatical (POS tagging). El reemplazo de sustantivos, verbos y adjetivos debe realizarse consultando diccionarios de sinónimos estructurados, respetando el tiempo verbal y género.
3. **Desambiguación del Sentido de las Palabras (WSD):** Garantizar que el sinónimo seleccionado coincida semánticamente con el contexto específico de la oración.
4. **Suavizado Contextual:** Aplicar un paso final de corrección gramatical y cohesión para que el resultado final fluya de manera natural.

**Repositorios e Integraciones Requeridas:**
Generar el código base en Python integrando obligatoriamente las lógicas de las siguientes herramientas y repositorios clave en la industria:

* **[makcedward/nlpaug](https://github.com/makcedward/nlpaug):** Utilizar para la implementación rápida de aumento de datos y sustitución de sinónimos a nivel de palabras (WordNet, PPDB, o diccionarios personalizados).
* **[explosion/spaCy](https://github.com/explosion/spaCy):** Implementar para el pipeline base de NLP, análisis morfológico, POS tagging y extracción de entidades nombradas (NER) en múltiples idiomas (para evitar reemplazar nombres propios).
* **Open Multilingual Wordnet (OMW):** Usar como base de datos de conocimiento léxico para mapear los sinónimos correctos cuando se detecten idiomas distintos al inglés.
* **[huggingface/transformers](https://github.com/huggingface/transformers):** Opcional, pero recomendado en el prompt, para integrar modelos de lenguaje ligeros (como T5 o modelos de traducción inversa/back-translation con MarianMT) encargados del paso final de "suavizado" del texto.

**Entregables Esperados en la Respuesta:**

1. Arquitectura modular del código (clases separadas para la inicialización de diccionarios, el motor de reescritura y el procesador de idiomas).
2. Un script ejecutable de demostración que procese una cadena de texto en español y otra en inglés.
3. Archivo `requirements.txt` con las versiones estables de las librerías mencionadas.

**Requisitos Avanzados: Manejo de HTML y Evasión de Contenido Duplicado (SEO)**

Además de la arquitectura base, el módulo debe implementar las siguientes dos características críticas:

**1. Preservación Estructural de HTML (Rich Text Handling):**
El texto de entrada puede contener formato HTML complejo (párrafos, negritas, enlaces, listas).

* Implementa un paso de preprocesamiento utilizando `BeautifulSoup` (o una herramienta similar).

* Una vez reescrito el texto, el sistema debe reinyectarlo en la estructura de etiquetas original con precisión quirúrgica, garantizando que el HTML de salida sea completamente válido y no esté roto.

* **Reestructuración Sintáctica:** Además de consultar diccionarios de sinónimos, el pipeline debe incluir reglas de reescritura a nivel de frase. Esto incluye la conversión entre voz activa y pasiva, la alteración del orden de las cláusulas y la fusión o división de oraciones mediante la manipulación de los árboles de dependencia sintáctica extraídos con `spaCy`.
